This catalogue lists the access packages defined in the Access Management source code. The code is authoritative for names, descriptions, URNs, authorisation areas and whether service owners may connect resources to a package.

- [See the package definitions in `PackageConstants.cs`.](https://github.com/Altinn/altinn-authorization-tmp/blob/main/src/apps/Altinn.AccessManagement/src/Altinn.AccessMgmt.PersistenceEF/Constants/PackageConstants.cs)
- [See the authorisation-area definitions in `AreaConstants.cs`.](https://github.com/Altinn/altinn-authorization-tmp/blob/main/src/apps/Altinn.AccessManagement/src/Altinn.AccessMgmt.PersistenceEF/Constants/AreaConstants.cs)
- [See the connections between roles and access packages in `IngestRolePackage.cs`.](https://github.com/Altinn/altinn-authorization-tmp/blob/main/src/apps/Altinn.AccessManagement/src/Altinn.AccessMgmt.PersistenceEF/Data/IngestRolePackage.cs)

The catalogue was checked against the source after commit `20fcb3f0`. Update it when the source definitions change.

The **Contents** column opens the package in [Tjenesteoversikten](https://tjenesteoversikten.no/packages) in a new tab. Tjenesteoversikten is an unofficial visualisation that uses Altinn's open APIs.
