title: "ALTINNAPP9999: unknown analysis error"
description: "The analysis failed with an unexpected error"
weight: 999
---

This diagnostic is reported when the analysis itself fails with an unexpected error. The message
contains the error type and the details from the exception.

Category `General`, severity **warning**.

As with ALTINNAPP0001, the message tells you to contact support. The rule points to the
analysis, not to the app code.
