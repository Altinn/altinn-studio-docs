Plattformen kjører på en sikker, isolert og skalerbar infrastruktur. Den er integrert mot flere fellesløsninger og åpne API-er.
Appene du lager i Altinn Studio, kan ha både brukergrensesnitt for manuell innsending og API-er for maskin-til-maskin-innsending.


## Hva kan du lage med Altinn Studio?
Med Altinn Studio kan du utvikle digitale tjenester for mange forskjellige formål. Det kan være alt fra enkle skjematjenester og innsynsløsninger til komplekse arbeidsflyter med betaling og signering. Plattformen støtter både tradisjonelle skjemaer og tilpassede apper med avanserte integrasjoner.

Se [eksempler på konkrete bruksområder](/nb/altinn-studio/v9/this-is-as/get-to-know-as/usecases).

## Altinn Studio er bindemiddelet
Et skjema er sjelden bare datafelter som skal sendes inn. Du trenger mer for å lage en god tjeneste. Det kan være:
- kobling mot ID-porten
- innsending til saksbehandlingssystem
- kobling mot nasjonale registre

Altinn Studio har ferdig utviklede integrasjoner mot flere av Digdirs fellesløsninger og nasjonale registre. Vi fortsetter å utvikle disse og legge til flere.

## Lavkode og tradisjonell kode
Altinn Studio kombinerer lavkode og tradisjonell koding. Du kan starte med lavkode i Altinn Studio Designer. Har du avanserte behov, kan du bytte til dedikerte utviklingsverktøy som Visual Studio Code.

Målet er å kunne gjøre mest mulig med lavkode, men beholde muligheten for tradisjonell koding og fleksibiliteten det gir. Slik kan folk uten teknisk bakgrunn designe og publisere tjenester uten å hente inn utviklere. Samtidig kan du hente inn en utvikler for å lage mer avansert funksjonalitet som krever koding.


## Prinsipper for Altinn Studio
Dette er noen av prinsippene som ligger til grunn når vi utvikler Altinn Studio:

- **Fri og åpen kildekode**: Vi tror at åpenhet og mulighet for andre til å bidra er veien å gå når offentlig sektor utvikler tjenester.
- **Basert på åpne standarder**: Lukket kode binder deg til én leverandør og gir ofte ekstra kostnader.
- **Skybasert infrastruktur**: Vi bruker løse koblinger og binder oss ikke til én skyleverandør.
- **Bygget på moderne og populære rammeverk**: Det gjør det lettere både for oss og kundene våre å skaffe teknisk kompetanse, og det er noe folk ønsker å jobbe med og lære.
- **Innebygd sikkerhet**: Hvert lag i arkitekturen autoriserer bruken uavhengig av hvor kallene kommer fra.
- **Isolasjon**: Hver tjenesteeier får sine egne miljøer for test og produksjon.

Les mer om [hvordan du kan bidra til å utvikle Altinn Studio](/nb/altinn-studio/v9/this-is-as/get-to-know-as/open-source).
